# Basic Weather App — Python

## Project Overview

This project is a Basic Weather App developed using Python as part of my Oasis Infobyte internship.

The application allows users to enter a city name and retrieve weather information using a weather API.

## Features

* Search weather by city name
* Fetch weather data from an API
* Handle invalid city names
* Handle network errors and API request failures

## Technologies Used

* Python
* Requests library
* Weather API

## Installation

Install the required Python library:

```bash
pip install requests
```

## How to Run

Run the following command in your terminal:

```bash
python weather_app.py
```

Enter a city name when prompted.
