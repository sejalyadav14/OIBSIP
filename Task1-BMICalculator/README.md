# Task 1: BMI Calculator 🧮

## 📌 Project Overview

The BMI (Body Mass Index) Calculator is a simple Python project that calculates a person's BMI based on their weight and height. It is designed to practice basic Python programming concepts and mathematical calculations.

## 🎯 Objectives

* Understand Python variables and user input.
* Perform mathematical calculations using Python.
* Apply conditional statements to categorize BMI.
* Build a beginner-friendly command-line application.

## 🛠️ Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## ✨ Features

* Takes weight as input in kilograms.
* Takes height as input in meters.
* Calculates Body Mass Index (BMI).
* Displays the BMI result.
* Shows a BMI category if implemented in the program.

## 📐 BMI Formula

**BMI = Weight (kg) / Height (m)²**

## 🚀 How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the BMI Calculator Python file.
5. Run the following command in the terminal, replacing the filename if necessary:

```bash
python bmi_calculator.py
```

6. Enter your weight and height when prompted.

## 📊 BMI Categories

For adults, commonly used BMI categories are:

* Below 18.5: Underweight
* 18.5–24.9: Healthy weight
* 25.0–29.9: Overweight
* 30.0 and above: Obesity
